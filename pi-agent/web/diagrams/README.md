# 电子书矢量图

## 范围

检查了全部 27 篇网页文章（源码篇 TS/Python 20 篇，实战篇 7 篇）。将 156 处图示替换成 91 张独立 SVG，复用完全相同的图；网页和 Markdown 下载版共维护 247 个图片文件。

- 包含层级树、架构框图、流程、事件时间线、并排对照，以及原先未渲染的一张 Mermaid 参数校验图。
- 代码字符串中的线条、HTTP 请求示例、摘要模板、调度伪代码仍保留为可复制示例，不误转换成图片。
- 只改展示形式，不修改图中的技术断言。全书源码核验进度仍以 `../../SOURCE-AUDIT.md` 为准。

## 原图与结构保真

`manifest.json` 保存原图输入、SHA-256、原文件和原代码块位置、转换/保留清单。它是制作与复核材料，不在网页正文里显示。

`../scripts/lib/diagram-svg.mjs` 按原图行列布置文字，使用 SVG path 绘制连接线、分叉和箭头，而不是截屏或把整段字符图包进一个 text 元素。保留上下顺序、左右分组、嵌套缩进和文字；手写框线因中英文宽度产生的一两格漂移会对齐到框线基准。SVG 文字可选择、放大不失真。

唯一 Mermaid 图按其五个节点与五条边重绘，保留合法/不合法两条分支和重试回边。

## 维护与检查

从 `pi-agent/web` 运行：

```bash
npm run diagrams
npm run check
npm run build
npm run check:pages
```

- `diagrams` 生成网页 public 图片和各 Markdown 目录的图片副本。
- `check:diagrams` 只检查生成物是否与输入一致，不静默更新文件；比较时统一 LF/CRLF，兼容 Windows checkout。
- 图中的单元宽度使用固定字符范围，不依赖宿主的 Extended_Pictographic 属性表，避免 Node 22/24 对 U+2605 的不同判定改变布局。
- `test/diagrams.test.mjs` 验证文字/连接符可按原行列完整还原、节点及分支、全部引用和未转换块的白名单。
- 普通代码示例不应为了消除字符匹配而被删除或改写。
- 新增或修改图示时，先检查含义与层级，再更新输入和 sourceSha256、生成图片、检查网页及下载版引用。

新增图片使用 `Diagram` 的 `layout="preserve"`：桌面保留原尺寸并允许横向滚动；1023px 及以下按容器宽度等比例缩放，默认显示完整图片。点击后可通过放大/缩小/适应屏幕按钮查看细节，放大后支持触摸滚动，不依赖鼠标滚轮。原图链接和打印适配仍保留。正文中的图数量用于 PDF 导出等待，不依赖 frontmatter 中的交互锚点数量。
